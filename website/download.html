Installing Pandion

Installing takes three steps.

  1. Download the file for your computer with the buttons above.
  2. Open the downloaded file and follow the installation steps.
  3. Launch Pandion Plots from Applications or the Start menu.

Using Pandion in jamovi?

Add the module to jamovi to build figures beside your analyses and keep them in the same .omv file.

Module for macOS (Apple silicon) Module for Windows Read the user guide

Install it in jamovi via the Modules menu: choose jamovi library, then use the sideload arrow to add the downloaded .jmo file.
