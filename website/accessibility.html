Accessibility

Making Pandion usable by more people.

Pandion Plots is an open-source product. Accessibility is a core product-quality commitment.

Our target

Pandion is being developed toward WCAG 2.2 Level A and AA across the public website and documentation, portable and Electron applications, exports, and jamovi integration. Work is still in progress, so this page is not a claim or certification of full conformance.

Current strengths

  • All seven chart families expose named, focusable charts and direct users to semantic statistical results.
  • The Data grid supports keyboard navigation and editing, with row and column relationships, missing-value descriptions, and edit status messages.
  • Layouts supports keyboard selection, movement, resizing, and text editing. Notebook supports keyboard selection, reordering, and page navigation.
  • The interface respects reduced-motion preferences and includes visible keyboard focus.
  • The public website and guide provide bypass links, responsive layouts, descriptive image alternatives, and keyboard-accessible navigation.
  • In the standalone editions, chart, Layouts, and Notebook PDFs include tagged figures, figure descriptions, document language, and page-order structure. Authors still need to review descriptions and provide exact values in an accessible companion table when needed.

What has been tested

As of September 10, 2026, local automated checks cover the standalone source, portable file, hosted-app build, public site and guide, and R-generated chart hosts. These checks include all seven chart families, major dialogs, keyboard and focus behavior, and exported PDF structure. Sampled grid, dialog, reflow, and text-spacing checks also run in Firefox and WebKit, in addition to Chromium.

These are development test results, not acceptance of complete workflows with assistive technology. Playwright WebKit testing does not establish Safari and VoiceOver support. The installed jamovi and Electron interfaces, live deployment, and downloaded files in the user's PDF reader need separate checks.

Known limitations

  • Complete workflows with NVDA, JAWS, VoiceOver, magnification, voice control, and disabled users have not yet been accepted in the current test record. Grid announcements, chart comprehension, Layouts and Notebook authoring, and saving and reopening files remain part of that work.
  • Installed jamovi needs testing of its data editor, analysis navigation, results frame, and file dialogs as well as Pandion's chart controls. Browser-based chart-host tests do not establish access through jamovi's surrounding interface.
  • Some default chart fills have insufficient contrast against white when used without outlines. Palette choice alone does not establish accessibility; required shapes, labels, and group distinctions need review in the final figure.
  • Gradient backgrounds, SVG text, and some native controls still have unresolved contrast review items. Actual browser zoom, high-contrast settings, and assistive-technology workflows need acceptance on supported platforms.
  • Exported figures may require a companion caption, long description, or data table. Tagged PDF structure does not by itself establish useful reading order or description quality in a screen reader; raster images need alternative text in the document or webpage where they are used.

Report an accessibility barrier

Email contact@pandionplots.com. Please include what you were trying to do, the page or application version, your browser and assistive technology if applicable, and any error message you encountered.

You may also request an accessible description, data table, documentation format, or help identifying an accessible route through a Pandion workflow. We will reply with the available workaround or remediation status.
