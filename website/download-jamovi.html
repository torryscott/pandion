Add Pandion Plots to jamovi.

Download the module for your computer, then add it from inside jamovi. It takes about two minutes, and every step is shown below.

Module download options

Step 1: download the module for your computer.

macOS Recommended for this device

Module for macOS

For Macs with an Apple chip (M1 or later).

Download pandion-macos-arm64.jmo Version 3.1.2 · about 13 MB ↓

Not sure which Mac you have? Open the Apple menu, choose About This Mac, and look for a chip named Apple M1, M2, M3 or M4. On an Intel Mac, use the desktop app or the browser app instead.

Windows Recommended for this device

Module for Windows

For 64-bit Windows 10 and 11.

Download pandion-win-x64.jmo Version 3.1.2 · about 14 MB ↓

The file ends in .jmo. It is not a program you run: jamovi reads it in step 4.

Both files come directly from the official Pandion Plots GitHub repository. The release page has the release notes and every file this release carries.

Install it inside jamovi

jamovi adds modules from its own library window, using a button called Sideload that reads the file you just downloaded. You do this once; the module stays installed.

1

Find the file you downloaded

Your browser saves it in your Downloads folder. Leave it there for now, and do not double-click it: jamovi will open it for you.

On a Mac, Safari sometimes unpacks downloads on its own. If you see a folder called pandion-macos-arm64 instead of a single file, delete the folder and download again with Chrome or Firefox, or turn off Open "safe" files after downloading in Safari's General settings and try once more.
2

Open jamovi and click Modules

Open jamovi (any data set, or none). At the far right of the ribbon, click Modules.

3

Choose jamovi library

A short menu opens. Click jamovi library. A panel slides in from the right, listing modules jamovi can install.

4

Click Sideload and pick the file

At the top-right of the library panel, click Sideload: a small arrow icon. A file window opens. Go to your Downloads folder, select pandion-macos-arm64.jmo or pandion-win-x64.jmo, and click Open.

5

Wait for the confirmation

jamovi installs the module in a few seconds and shows Module installed successfully. Close the library panel with the arrow at its top-left.

6

Make your first chart

Click Modules again: Pandion Plots is now listed there, with its seven chart types and the Help Me Choose guide. Pick one, drop a variable or two into the boxes, and the chart draws itself beside your analyses, saved in the same .omv file.

If Pandion Plots does not show up right away, quit jamovi and open it again.

If something goes wrong

Sideload is missing or greyed out

Sideloading needs the jamovi desktop app on your own computer. jamovi Cloud and some managed installations do not allow it; use the browser app there.

jamovi says the module needs a newer version

The module needs jamovi 2.7.32 or later. Update jamovi from jamovi.org, then repeat step 2.

The file will not open on a Mac

The macOS module is built for Apple chips (M1 or later). On an Intel Mac, install the desktop app instead; it makes the same charts.

Updating later

Download the new file from this page and repeat steps 2 to 4; jamovi replaces the older version. To remove the module, choose Modules, then Manage installed, then Remove.
