Add Pandion Plots to jamovi.

Download the module for your computer, then add it from inside jamovi. It takes about two minutes, and every step is shown below.

Intel chip

Install it inside jamovi

jamovi adds modules from its own library window, which has a Sideload tab for a file you downloaded yourself. You do this once; the module stays installed. The screenshots show jamovi 2.7; jamovi 28 looks the same at every step.

1

Find the file you downloaded

Your browser saves it in your Downloads folder. Leave it there for now, and do not double-click it: jamovi will open it for you.

On a Mac, Safari sometimes unpacks downloads on its own. If you see a folder called pandion-macos-arm64 or pandion-macos-x64 instead of a single file, delete the folder and download again with Chrome or Firefox, or turn off Open "safe" files after downloading in Safari's General settings and try once more.
2

Open jamovi and click Modules

Open jamovi (any data set, or none). At the far right of the ribbon, click Modules.

3

Choose jamovi library

A short menu opens. Click jamovi library. A panel slides in from the right, listing modules jamovi can install.

4

Click the Sideload tab, then the big arrow

A window titled jamovi opens with three tabs: Installed, Available and Sideload. Click Sideload, then click the large arrow in the middle of the window. A file window opens: go to your Downloads folder, select the file you downloaded (its name starts with pandion- and ends in .jmo), and click Open.

5

Check the Installed tab

jamovi installs the module in a few seconds and shows Module installed successfully. Click the Installed tab and scroll down: pandion - Plots is listed with its version number. Close the window with the round arrow button at its top-right.

6

Find it on the Plots tab

Click the Plots tab at the top of the ribbon. A Pandion Plots button is now there, next to jamovi's own plots.

Click it to see the seven chart types and the Help Me Choose guide. Pick one, drop a variable or two into the boxes, and the chart draws itself beside your analyses, saved in the same .omv file.

If the button does not show up right away, quit jamovi and open it again.

If something goes wrong

Sideload is missing or greyed out

Sideloading needs the jamovi desktop app on your own computer. jamovi Cloud and some managed installations do not allow it; use the browser app there.

jamovi says the installed version needs to be updated

That message means the file does not match your jamovi or your Mac: the jamovi 2.7 file in jamovi 28 or the other way round, or a Mac file for the other type of chip. Updating jamovi does not change it. Remove the module from the library's Installed tab, download the matching file above, and repeat step 4. On jamovi 2.7 you need 2.7.32 or later; older 2.7 releases can be updated from jamovi.org.

Updating later

Download the new file from this page and repeat steps 2 to 4; jamovi replaces the older version. To take the module out, open the library window's Installed tab and click Remove on the pandion entry.
