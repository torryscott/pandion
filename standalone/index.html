Missing values

What counts as missing, and the dataset list every variable starts with.

A cell counts as missing when it is blank, or when its text matches one of the codes shown as chips in the panel. Missing cells are left out of charts and statistics.

Blank cells always count as missing. That is why the blank chip has no remove button.

The two lists. Every variable starts with the dataset list below. Editing a variable's chips gives that variable its own list, which REPLACES the dataset list for it alone: that is how a code can mean missing in most variables but stay a real value in one of them. The line under the chips says which is in force, "Same as the rest of the dataset" or "Different from the dataset now". When a variable differs, that line offers both ways to end the difference: take the dataset's values here, or make this variable's values the dataset's.

What a code does. Surveys often store an unanswered question as -99, or "not applicable" as 9. Declaring the code does not change any cell: the value stays in the table, and the app stops counting it as data.
