Welcome

What is Pandion Plots?

Pandion Plots is a graphing app for clear, customizable statistical figures. It runs in your browser, as a portable download, as a desktop app for macOS and Windows, or as a jamovi module in the ribbon's Plots tab. The chart editor is identical in all of them, so everything in this guide applies wherever you are working. It is organized around seven chart analyses and one guide.

AnalysisWhat it is for
DistributionThe shape and spread of one numeric variable: histograms, density curves, box / violin / raincloud, a dot plot of every value beside its mean, Q-Q plots, ECDF.
FrequenciesCounts or percentages of a categorical variable: bar (side-by-side, stacked, 100%), pie, donut, Pareto, with chi-square tests.
Compare GroupsA numeric outcome across the levels of a categorical variable (different people in each group): bar, line, dot, box, violin, raincloud. Reach for bar or dot when the categories have no natural order; a line implies a trend, so save it for ordered steps (doses, grades, sizes) - the Check graph tab flags a line drawn over unordered categories, and when the category names are themselves numbers, line and dot charts can space them by value rather than evenly.
Repeated MeasuresThe same people measured on two or more occasions (wide data, one column per occasion), with within-subject error bars.
ScatterThe relationship between two numeric variables, with fit lines, confidence bands, data ellipses, marginals, and a heatmap mode for big samples.
Correlation MatrixAll the pairwise correlations among two or more numeric variables, as a heatmap, circles, numbers, or a mixed matrix.
Likert / SurveyA battery of rating-scale items that share one response scale: diverging stacked bars, 100% stacked bars, or item means with CIs.
Help Me Choose (under a "Guide" divider)Not a chart: a question-driven wizard that recommends which analysis and chart type fit your goal or your exact variables.

The three ideas behind it

  • Beautiful defaults. Drop in one or two variables and the chart is already presentable: an accessible 8-color palette designed to remain distinct across Pandion Plots' color-vision simulations, clean axes, sensible error bars.
  • Everything is click-to-edit. The variable panel (jamovi's options panel, or the app's Chart setup column) stays tiny on purpose. Colors, fonts, axes, legends, labels, spacing, ordering: you edit them by clicking the thing itself on the chart. A style panel opens right below the chart.
  • Honest statistics. Significance brackets compute real tests from your raw data, disclose their corrections, and refuse politely when a test does not apply. A built-in Check graph tab scans your chart for the classic misleading-graph pitfalls before you export it.

Installing

Pandion Plots runs four ways, and the chart editor is the same in each.

The browser and portable editions share one project file (.pand), so a project moves freely between them, and the desktop app reads the same file. Inside jamovi your charts are saved in the .omv file alongside your analyses instead; jamovi and the app do not share a project file, though both read .omv data.

In your browser. Go to pandionplots.com/app. There is nothing to install, and your data never leaves your machine.

As a portable file. Download the single-file version from pandionplots.com. It runs offline in any browser, and you can copy it to a USB stick or email it to students.

As a desktop app. Download the macOS or Windows installer from the download page: the same app in its own window, with no browser around it.

As a jamovi module.

  1. In jamovi, click the Modules button (the large + at the top-right of the ribbon).
  2. Choose Sideload (the sideways arrow icon) and pick the .jmo file for your jamovi from the module page, which walks through the install with screenshots. There are two module lines, one for jamovi 28 (the current jamovi) and one for the jamovi 2.7 line, each as a macOS (Apple silicon) file and a Windows file. A 2.7 file does not load in jamovi 28, nor the other way round; jamovi then says the installed version needs to be updated, so pick the file that matches your jamovi. The same files are on the releases page. (Once Pandion Plots is listed in the jamovi library, you will be able to install it from there instead.)
  3. A Pandion Plots menu appears in the ribbon's Plots tab. If it does not show up right away, restart jamovi.

The app's four workspaces

The app wraps the chart editor in four workspaces, switched from the left rail (or Ctrl+1 through 4 on a Mac, Ctrl+Shift+1 through 4 elsewhere - macOS keeps Cmd+Shift+3 and 4 for its own screenshots).

Guided tours. Five short tours introduce the rooms: Help > Tour the app, Tour the Data workspace, Tour the Charts workspace, Tour the Notebook, and Tour the Layouts workspace. Each one spotlights the room's landmarks one card at a time (Next and Back step through, Esc exits) and never changes your project. The start center offers the app tour as New here? Take the two-minute tour, an empty workspace offers its own tour as New here? Tour this workspace until you have taken it, and the note on your first chart has a Tour this workspace button.

Data

A spreadsheet for your data: import CSV, Excel, or a jamovi .omv (drop the file anywhere, or paste cells straight in), type and edit values, set each variable's measure type, exclude individual values or whole rows without deleting them, declare codes like 999 as missing so they leave every chart and statistic (with a live count of what each code excludes), and search with Cmd/Ctrl+F. The File menu exports the sheet back out as CSV or Excel. Computed variables live here too - see Computed variables below.

The grid sizes each column to its content by default; double-click a column edge to re-fit one, or use Data > Auto-fit all columns and Reset all column widths. The same menu holds the column and row commands: insert, duplicate, delete, and move columns; insert, duplicate, and delete rows; Sort rows ascending / descending; Fill down from the selected cell; Hide column, Show all columns, and Show only chart variables (just the columns the active chart uses); and Restore all exclusions. The Insert menu repeats the four insert commands (column to the left or right, row above or below) for anyone arriving from Excel or SPSS.

Row filters keep a subset of your rows without deleting anything. Build conditions from the Filter button in the Data workspace toolbar (it shows a row count while a filter is active); several conditions all have to pass. A row that fails one stays visible in the grid, dimmed, but leaves every chart and every statistic, so counts and percentages describe exactly the rows you kept. Clear the filter and the rows come straight back.

Reshape to wide (Data menu) turns long data into the one-row-per- subject shape Repeated Measures expects. It refuses rather than guess when your data would lose information, and explains what it found so you can fix it.

The variable inspector opens when you select a column: a summary of the column (its mode included), advice on its measure type, and its list of levels, which you can drag into the order you want the chart to use.

Charts

Each chart is its own document in the tab strip: rename by double-clicking the tab, reorder by dragging, duplicate or delete from the right-click menu, and collect related charts into groups in the left rail. The chart itself is the full editor this guide describes.

Clicking a part of the chart opens its editing panel under the chart. On a window too short to show the chart and the panel together, the panel docks beside the chart instead, in place of Chart setup, for as long as something is selected. Edit > Preferences > Chart editing panel makes that choice fixed: Automatic, Under the chart, or Beside the chart.

Notebook

Your lab notebook of frozen moments. Right-click a chart and choose Keep to Notebook, or press Keep on a pinned comparison in the Σ Statistics panel, and the capture lands as a page: the chart, its selection rings, and the statistics as one image. Pages are organized into sections (tabs at the top), carry when they were kept, your notes, and an honest verdict on whether the source chart has changed since. Kept pages are records: they never update themselves, which is the point.

Right-click a page for its verbs: Copy image, Send to layout..., Move to section..., Keep an updated copy, Export this page..., and Delete page. Keep an updated copy is offered once the verdict reads "source chart has changed": it keeps the current chart as a new page directly below the old one, carrying the note and the title forward, and both versions keep their own kept dates. A page whose chart was deleted reads "source chart is gone".

Layouts

Multi-panel figure assembly: place live chart panels (they follow their source chart), kept Notebook pages, images, and text on a page sized for slides or paper, then export the whole page. Right-click any placed panel for Open source chart. The Insert menu adds a Chart panel, Text, a Panel label, or an Image... to the page, and Insert > New layout starts another.

Saving and opening

Save writes a .pand project: the data, every chart and its styling, layouts, and the Notebook, all in one file. The app also keeps a local autosave as you work, so a closed tab or crash recovers your session on the next visit. Your saved palettes and chart styles live in your own library on this machine, and a copy of that library is written into every .pand project you save, so a look you built travels with the file. Opening a project adds any palettes or styles it carries that you do not already have; entries you already own are never overwritten. The File menu also keeps Open recent, Restore (reopen a document you closed), and Rename project....

Preferences, the command palette, and updates

Edit > Preferences... (Cmd/Ctrl+,) holds the settings that follow you rather than any one project, in two tabs. General: interface density (Compact / Comfortable / Spacious), motion, what to show on launch (the start center or your autosaved project), the default export format, measurement units for layouts (inches, centimetres, or pixels), the default chart style for new charts, the default raster DPI, whether to check for updates automatically (off by default; at most one version-number request a day, and nothing about you or your data is sent), where the chart editing panel opens, and the default missing-value labels for imports. Statistics: the starting error-bar type for new Compare Groups and Repeated Measures charts (Difference-adjusted included), the Repeated Measures method (within-subject or between-subjects), and the alpha level. Statistics preferences only seed new charts; existing charts never change when a preference does. A Local data section at the bottom shows what the app stores on this machine, with Clear local data... and Restore defaults.

View > Command palette... (Cmd/Ctrl+Shift+P) lists every menu command in one searchable box: type part of its name, pick it with the arrow keys, and press Enter. It is the fastest route to anything in the menus when you know the name but not the menu.

Help > Check for updates... asks pandionplots.com for the newest version number and replies "You are up to date (3.1.3)" when nothing newer exists. It matters for the portable file and the desktop app; the browser edition at pandionplots.com is always the current release. Help > What's new lists what changed in each release.

Computed variables

In the Data workspace, a computed variable is a formula that recalculates whenever the data changes: open it from the column menu, name the variable, and type a formula. A computed column wears a small fx badge in its header so you can spot it at a glance. Use column names directly; backtick-quote names with spaces. The Functions list in the dialog is the guided way in: it opens with a Common recipes group (z-score, Center, Difference, Percent change, Reverse-score, Recode), and clicking any entry asks for the column or columns it needs, then writes the finished formula into the box for you - at the cursor, so clicks and typing mix freely.

Recipes worth stealing - every formula below is verified against the app by an automated check, so they run as written. The column names are illustrative: supported, paced, clear, and useful stand for items in a five-item survey, and score comes from the Dose response study example on the welcome screen. Swap in your own column names.

GoalFormulaNotes
Reverse-score a 1-5 item 6 - supported The recipe builder writes this for you: pick the item and set where the scale starts and ends. It reverses around start plus end, so a 1-7 item gives 8 - item and a 0-4 item gives 4 - item.
Scale mean across items MEAN(paced, clear, useful, supported) MEAN only averages - it never reverse-scores anything. Reverse-score any reversed items yourself first (the Reverse-score recipe does one item at a time), then average the corrected columns. A person who skipped an item gets no score; add ignore_missing = 1 inside the brackets to score them from the items they answered (and say so in your write-up).
z-scores (score - VMEAN(score)) / VSD(score) The same thing the z-score recipe writes.
Center a variable score - VMEAN(score) Handy before interactions; the Center recipe.
Tame a skewed variable LOG10(rt) LN and SQRT work the same way.
Difference score post - pre Positive = improvement when higher is better.
Split at the mean IF(score >= VMEAN(score), "high", "low") Text results make a nominal variable, ready for Group By.
Equal-count bins BIN(score, 4) Labels the rows "bin 1" through "bin 4" (quartile groups).
Flag extreme values IF(ABS(score - VMEAN(score)) / VSD(score) > 3, 1, 0) 1 = more than 3 SDs from the mean. Investigate before excluding.
Round for display ROUND(score / 10) FLOOR and CEILING round down / up.
Fill a gap from another column COALESCE(post, pre) The first value that is there. Add more fallbacks as you like, and a number last for a value that can never itself be missing.
Flag the rows with no value ISMISSING(post) 1 where the cell is empty, 0 where it is not. Everything else in the language goes missing when its input does, so this is the way to ask.
Substitute for a missing value IF(ISMISSING(post), 0, post) Say why in your write-up. Treating an absence as a zero is a claim.
Tidy up messy category labels IF(CONTAINS(LOWER(TRIM(arm)), "control"), "Control", "Treatment") Folds "Control", "control" and "CONTROL" into one level, ready for Group By. LOWER and UPPER fold the case, TRIM tidies the spaces, LEN counts characters.
Names with spaces `first quiz` * 2 Backticks around the name, exactly as typed in the header.
TipFormulas recompute whenever the data changes, so a computed column is always current - unlike pasting values in. A formula that refers to itself (directly or through another computed column) is refused with an error naming both columns, and a broken formula flags its column's fx badge with the reason.

On-chart controls: Bar, Line, and Dot can summarize with a Mean or Median. Mean summaries can show Standard Error, Standard Deviation, a 95% or 99% Confidence Interval, a Difference-adjusted interval (scaled for comparison: when one group's mean falls outside another group's interval, the two differ at p < .05 on a two-sample t test), or no error bars; median summaries draw no SE / SD / CI bars. Bar

Compare a summary (mean or median) across a few groups. Quick magnitude comparison, but it hides the distribution.

Line

Show a trend across an ordered X axis (time, dose). Avoid for unordered categories.

Dot

Each group's summary as a single dot with an error bar. Read by position, so it does not need a zero baseline the way bars do.

Box

Each group's centre and spread: median, middle 50% box, whiskers, outliers.

Violin

The full distribution shape (fatter = more data). Best with larger samples.

Raincloud

Distribution, a small box, and every raw point at once. The most transparent option.

Special features

  • Significance brackets with real tests computed from your raw data (see Significance brackets), plus a full pairwise-comparison and ANOVA suite in the Σ Statistics panel.
  • Value labels and N labels on bars ("+" menu). N labels also work on box / violin / raincloud.
  • Individual data points and outlier markers as overlays ("+" menu).
  • Ordering: drag categories or series directly on the chart, use the Order tab's compact up / down controls for an exact one-step move, or use that tab's Order select to sort the categories by their values (lowest or highest first).
  • Value spacing (line and dot charts): when every category name is a number (doses of 0, 10, 40), the panel's Gap tab offers "Space categories by their value", so the categories sit at their real distances apart instead of in equal slots. Repeated Measures keeps the same toggle.
  • Gap seams (app only): hover the space between bars, wait a beat, and a seam handle appears; drag it to widen or narrow the gap between categories or between the bars of a group, and the panel's Gap tab follows the drag live. On grouped line and dot charts the seam sets the marker spread instead. The same seams work on Repeated Measures, Frequencies bars, the Distribution box family, and the Likert row gap.
  • Panels: an assigned Panels variable draws one mini-chart per level, with a clickable heading strip on each.

Variable boxes: different from the other modules. In jamovi, Repeated Measures uses the same factorial input as jamovi's own RM-ANOVA:

  • Repeated Measures Factors: type the name of each within-subjects factor and its level names (e.g. a factor "Time" with levels T1, T2, T3).

Variable boxes. In the app, Repeated Measures takes a flat list rather than a factorial grid:

  • Repeated measures: add the measurement columns in the order they were collected. Each one becomes an occasion on the x-axis.
  • Between-groups variable (optional): a categorical variable that splits the repeated pattern into colored groups.
  • Panels (optional): a categorical variable that draws a separate mini-chart per level.

On-chart controls: Summary (Mean / Median), plus an Error bars tab whose Type control contains SE / SD / 95% CI / 99% CI / Difference-adjusted / None; the Difference-adjusted reading (a mean outside another group's interval differs at p < .05) is exact for within-subject comparisons. On Repeated Measures, that same Type surface includes a Method subsection: "Within-subjects (Cousineau-Morey)" (default) or "Between-subjects (uncorrected)". Median summaries draw no SE / SD / CI bars.

Arranging a factorial design. With two or more factors, a small strip under the toolbar offers three dropdowns (X-axis, Grouped by, Panels) so you can pivot any factor onto any slot instantly.

Line (default)

Joins each occasion so you can read the trend across time or conditions.

Bar

A summary per occasion with a within-subject error bar.

Dot

A dot at each occasion's summary, no connecting line.

Between-subjects group

Four practice sessions per person, timed for two groups: occasions along the axis, the Group By variable as color.

Special features

  • Crossed within-subjects factors (jamovi only): put the occasion columns in Repeated Measures Cells and name the factors in Repeated Measures Factors, and two within-subjects factors share one chart, one along the axis and one as colored series.
  • Per-subject overlays ("+" menu): Data points shows every subject's raw values; Connect subjects draws each person's own line across occasions ("spaghetti"), so you can see whether individuals follow the average trend.
  • Paired and mixed tests by design. Significance brackets between occasions default to a paired t-test, joined subject-by-subject. The Statistics panel's Omnibus tab reports repeated-measures effects for within-subject designs and mixed (split-plot) effects when supported between-subject factors or panels are present; within-subject rows use the Greenhouse-Geisser correction when needed.
  • Box / violin / raincloud show each occasion's full distribution.
  • The Y-axis title starts empty on purpose, as a nudge to name your measure (the Check graph tab reminds you until you do).

The hidden-data rule

One rule, stated everywhere

On measurement charts (Compare Groups, Repeated Measures), hiding is excluding. Hide a bar or points and the brackets and ANOVA recompute without them, matching the drawn error bars, which already do. The readouts disclose it.

On count charts (Frequencies) and in the Σ tables, hiding is decluttering. The chi-square, proportion tests, and those tables keep the full data: hiding a bar never silently changes an N, a percent, or a p. The one exception is the Scatter Σ table, which drops rows for hidden groups outright and says so in the panel.

The Σ panel, the bracket readouts, and the Check graph tab all state which side of the rule your chart is on whenever anything is hidden.

Significance and uncertainty

p value (p) · Compare, RM, Freq, Dist, Corr, Likert, Scatter

A p value asks: if the stated null hypothesis and the test's assumptions were true, how often would the test statistic be at least as extreme as the one observed? A smaller p means the data are less compatible with that null model.

How to read it. Compare p with the alpha level chosen for the analysis; p = .03 means 0.03. When practical, report the exact p together with the effect estimate and its uncertainty.

Common misread. A p value is not the probability that the null is true, that chance caused the data, or that an effect is real. It also does not measure effect size or scientific importance.

p adjusted (p (adj)) · Compare, RM, Freq, Corr

An adjusted p value accounts for a defined family of several tests. Bonferroni, Holm, and Benjamini-Hochberg modify the raw p values. Tukey, Games-Howell, and Dunnett instead calculate multiplicity-adjusted p values from their own comparison models.

How to read it. Compare the reported value directly with alpha, and state which adjustment was used and which tests formed the family.

Common misread. Bonferroni, Holm, and BH adjusted values cannot be below their raw p values. Tukey, Games-Howell, and Dunnett may differ from a separate raw-test p because they use different statistics or error models.

significant at .05 · Compare, RM, Freq, Corr, Scatter

At alpha = .05, a result is called statistically significant when its relevant p value is below .05. This means the result crossed a chosen decision threshold; it does not prove that the finding is true.

How to read it. Pandion Plots flags p < alpha and does not flag p >= alpha. Choose alpha as part of the analysis plan, considering the costs of false positives and false negatives.

Common misread. Statistical significance does not establish a large, important, replicable, or causal effect. Non-significance does not establish equivalence or absence; those claims require suitable interval or equivalence methods.

degrees of freedom (df) · Compare, RM, Freq, Dist, Corr, Scatter

Degrees of freedom count how many values in your calculation are free to vary. Depending on the test they track your sample size, the number of groups or conditions, or the size of the table. They set the shape of the distribution a test uses to find its p value.

How to read it. Report it alongside the test statistic, for example t(38) or chi-square with df in parentheses. For t and F tests larger df mainly comes from more data; for chi-square it comes from the number of categories, not the sample size.

Common misread. df is bookkeeping for the test, not a finding: do not interpret it as an effect or a result on its own.

sample size (N and n) · Compare, RM, Freq, Dist, Corr, Likert, Scatter

Sample size is the number of non-missing units contributing to an estimate or test. The unit might be a person, trial, school, or something else. Capital N often means the full analysis sample and lowercase n a group or cell, but notation varies.

How to read it. Check what the unit is, how missing values were handled, and the n for each result. Different correlations can use different cases, and some repeated-measures tests require complete subjects.

Common misread. Rows are not always independent units. Repeated or clustered observations may provide less independent information than the raw row count suggests. A large N improves precision but does not make an effect important, unbiased, or causal.

95% confidence interval (95% CI) · Compare, RM, Dist, Corr, Likert, Scatter

A 95% confidence interval comes from a method designed, under its assumptions, to capture the true population value in 95% of repeated samples. The interval from this dataset is one result from that method.

How to read it. Its width shows precision under the model: narrower intervals are more precise. For a two-sided test using the same method, an interval that excludes 0 corresponds to rejecting a zero effect at alpha = .05; that does not make the effect important.

Common misread. The 95% is not the probability that the fixed population value lies inside this one interval, and the interval does not usually contain 95% of individual observations.

multiple comparisons · Compare, RM, Freq, Corr

When several tests are run, each true null hypothesis brings a chance of a false positive, so the chance of at least one false positive is usually larger than the alpha for one test. Multiple-testing methods control a chosen error rate across a defined family, such as the chance of any false positive or the expected false-discovery proportion.

How to read it. Decide which tests belong to the family from the scientific question, then use the adjusted p values or decisions from the chosen method.

Common misread. The risks from separate tests do not simply add; their sum is only an upper limit. A correction also cannot make an undisclosed, data-driven search into a planned confirmatory analysis.

Error-bar type (SE / SD / CI) · Compare, RM, Likert

SD bars show how spread out the observed values are. SE bars show how precisely a mean is estimated. Confidence-interval bars extend an SE using the selected confidence level. These mean-based bars are not drawn for median summaries.

How to read it. Always state which type is shown. For repeated measures, also state whether the bars use within-subject Cousineau-Morey normalization or ordinary between-subject spread.

Common misread. Overlap or non-overlap of separate error bars is not a general pairwise significance test. Use the appropriate comparison and its interval or p value.

Two-tailed vs one-tailed test · Compare, RM, Freq

A two-sided test allows differences in either direction. A one-sided test is set up for one direction chosen before seeing the data. A result in that direction is evaluated in that tail; a result in the opposite direction receives a large one-sided p value.

How to read it. Use a one-sided test only when the direction was specified in advance and a result in the opposite direction would not support the claim. Pandion Plots labels one-tailed results explicitly.

Common misread. Choosing the direction after seeing the estimate or switching tails to cross alpha invalidates the advertised error rate.

Significance bracket · Compare, RM, Freq

A significance bracket is an added bracket that spans two bars and labels the comparison between them. You can type the label yourself, or tick 'Auto-compute p-value from raw data' on its Stats tab to run a real test live and show the p-value, stars, or a full APA line. Drag each bracket leg onto a bar to pick the two groups.

How to read it. A bracket means that the two groups were selected for comparison. If its label was computed automatically, read the p value or stars using the stated test and alpha; a typed label is only an annotation.

Common misread. A bracket reports only the pair it spans. No bracket between two groups does not show that they are equal, and a bracket by itself does not show a large or important effect.

n.s. / significance asterisks · Compare, RM, Freq

This is the star shorthand for p thresholds: * for p < .05, ** for p < .01, *** for p < .001, and 'n.s.' for not significant. The chart's chosen alpha decides which marks SHOW: at alpha .01 a p of .03 reads n.s. even though it clears .05, and at alpha .10 a p between .05 and .10 earns a dagger (†) for marginal significance. The ladder itself never moves.

How to read it. Read more stars as a smaller p, and 'n.s.' as 'the difference did not reach this chart's cutoff' (alpha .05 unless it was changed).

Common misread. More stars mean a smaller p, not a bigger or more important effect, significance and effect size are different things.

Confidence / coverage level (Level %) · Compare, RM, Dist, Scatter, Likert

The level is the long-run target for how often an interval method captures the fixed population value, assuming the method's model is correct. With the same data and method, a 99% interval is wider than a 90% interval because it uses a larger margin.

How to read it. The level describes the method across repeated samples; the interval's width shows the precision obtained from this dataset.

Common misread. It is not the probability that the fixed value lies in this one interval. Except for displays specifically designed to cover data, it is also not the percentage of raw observations inside.

Effect sizes

Cohen's d (d) · Compare

For two independent groups, Cohen's d is the difference between the group means measured in standard deviation units (pooled spread next to Student's t; the average of the two variances next to Welch's t, matching jamovi). It tells you how far apart the groups are, on a scale that does not depend on the original measurement units.

How to read it. Read it as the number of standard deviations separating the two means: larger absolute values mean the groups are further apart, and the sign just reflects which group is higher.

Common misread. A large d means the groups differ a lot, not that the result is more certain or more statistically significant; and Cohen's 0.2, 0.5, 0.8 labels are rough conventions, not fixed rules.

Cohen's dz (paired) (dz) · RM

For paired or repeated measurements, Cohen's dz is the mean of the paired differences divided by the SD of those differences.

How to read it. The sign shows the direction of the mean difference. A larger absolute value means the mean difference is larger relative to how much the paired differences vary.

Common misread. It does not describe a typical person's change and is not directly interchangeable with independent-group d. Fixed small/medium/large labels are context-dependent.

Hedges' g (g) · Compare, RM

Hedges' g is Cohen's d with a small correction for the slight overestimation d has in small samples. You read it on the same standard deviation scale as d.

How to read it. Read it exactly like d, as a mean difference in standard deviation units, with values in small samples pulled a little toward zero compared to d.

Common misread. Several Hedges-g conventions and correction formulas exist. Report the software and denominator convention when exact cross-study comparability matters.

rank-biserial r (r) · Compare, RM

A rank-based effect size from -1 to +1. For Mann-Whitney, it summarizes whether observations from one independent group tend to outrank those from the other. For Wilcoxon, it compares the positive and negative ranked paired differences.

How to read it. Values near 0 show little overall rank advantage; values nearer -1 or +1 show that the ranked evidence falls mostly in one direction. Check group order before interpreting the sign: Pandion Plots follows jamovi's convention, which can point opposite to Cohen's d.

Common misread. It is not Pearson correlation, and it does not by itself estimate a difference in means or medians.

eta-squared (eta2) · Compare, RM

Pandion Plots calculates eta-squared for an ANOVA term by dividing that term's sum of squares by the total corrected sum of squares. In a one-way ANOVA, it is the usual share of the sample's total variation associated with group differences.

How to read it. For example, .10 means that the term's sum of squares is 10% of the total corrected sum of squares under this ANOVA calculation.

Common misread. In a factorial Type III ANOVA, adjusted terms can overlap, so their eta-squared values do not have to add to 1. Eta-squared also tends to overestimate the corresponding population effect.

Partial eta-squared (partial eta2) · Compare, RM

Partial eta-squared compares the variation linked to one ANOVA term with that term's variation plus its own error variation. Repeated-measures terms use the error term defined by their design.

How to read it. It runs from 0 to 1. Read it as the term's variation divided by that variation plus its own error,not as a share of all outcome variation.

Common misread. Values across terms do not add to 1 and depend on the design and error denominator. Do not compare them as though they were slices of one common whole.

Omega-squared (omega2) · Compare, RM

Omega-squared estimates the share of population variance associated with an ANOVA effect while correcting some of eta-squared's upward bias. It is often smaller than eta-squared, and an estimate can be zero or negative.

How to read it. Treat a small negative value as an estimate near zero, not as negative variance. Formula conventions differ across designs, so report the software or method when comparing studies.

Common misread. Bias correction does not make omega-squared assumption-free; it inherits the ANOVA model and design assumptions.

R-squared (R2) · Scatter

R-squared is the proportion of the variation in the outcome that the fitted line or model accounts for. It runs from 0 to 1, where 0 explains none of the spread and 1 explains all of it.

How to read it. Read it as the fraction of the outcome's variation captured by the fit: 0.25 means the model accounts for about 25 percent of the spread.

Common misread. A high R-squared means the model fits the spread of these data well, not that the relationship is causal or that predictions will be accurate for new cases.

Tests and their statistics

Welch's t-test (t) · Compare

A test of whether the population means of two independent groups differ. It allows the two populations to have different variances, or amounts of spread, and is generally the safer default when equal variance is uncertain.

How to read it. A larger t (further from 0) means a bigger group difference relative to noise; check the p value and the difference in means to judge it.

Common misread. Welch still assumes independent observational units and a meaningful mean with an adequate normal or large-sample approximation. It does not fix clustering, dependence, severe data errors, or selection bias.

Student's t-test (t) · Compare

A test of whether the population means of two independent groups differ. It pools the group variances, so it assumes that the two populations have equal variance, or similar spread. Welch's version is usually preferred when that assumption is doubtful.

How to read it. Read t the same way as Welch: further from 0 means a bigger difference relative to noise, and you still look at the p value and the size of the difference.

Common misread. It assumes independent observational units, equal population variances, and the usual normal or large-sample approximation. Equal-looking sample SDs do not prove equal population variances.

paired t-test (t) · RM

A test of whether the population's average paired difference is zero,for example, when the same people are measured before and after. It works on each matched pair's difference score.

How to read it. t is the mean difference divided by its SE. The sign shows direction; report the mean difference, confidence interval, and p value rather than t alone.

Common misread. Pairs must be correctly matched and independent of other pairs, and the difference-score mean needs an adequate normal or large-sample approximation. Significance does not mean every unit changed or that change was large.

Mann-Whitney U (U) · Compare

A test for two independent groups that works with ranked values rather than means. In general, it asks whether values from the two groups tend to occupy different ranks; it is not automatically a test of medians.

How to read it. Use the p value to assess the rank-distribution difference and report both groups' distributions plus a rank-based effect size. If the group distributions have similar shapes, the result can be interpreted as a location shift; if their shapes differ, the test can respond to those differences too.

Common misread. Skewness alone does not make Mann-Whitney preferable to Welch's t-test. Different shapes can produce significance even when medians are equal.

Wilcoxon signed-rank (V) · RM

A paired test that ranks the sizes of nonzero differences, then compares ranks attached to positive and negative differences. Its usual null assumes the difference distribution is symmetric around zero; under that assumption, it tests whether the distribution is centered at zero,technically, whether its pseudomedian is zero.

How to read it. Pandion Plots reports V as the sum of positive ranks. Use its p value to assess the signed-rank imbalance, and also report the paired differences and a rank-based effect size.

Common misread. The test uses both signs and ranked magnitudes, so it is not assumption-free and is not generally justified by saying the scores are merely ordinal or skewed.

Which test? · Compare, RM

Welch's t is the default for comparing two independent group means: it does not assume equal spread, and when spreads happen to be equal it gives nearly the same answer as Student's t, so it costs almost nothing. Testing for equal variances first and then choosing a test is worse than either test used alone (the pretest misses trouble in small samples and distorts the overall error rate), so Pandion Plots never does it. Student's t stays available for teaching or matching a textbook. Mann-Whitney U answers a different question (whether one group's values tend to be larger, not whether means differ), so reach for it when the outcome is ordinal or when the mean is not the summary you care about.

How to read it. Leave Test on Auto: it picks a paired test when the two cells are the same subjects and Welch's t otherwise, and the readout always names what ran.

Common misread. Skewed or non-normal data alone is not a reason to switch to Mann-Whitney: at moderate sample sizes the t family handles it, and under unequal spreads Mann-Whitney has error problems of its own that Welch's t does not.

the t statistic (t) · Compare, RM

A single number that scales the size of a difference by the noise around it, so bigger differences and less noise both push it away from 0. It feeds into the p value; on its own it is a signal-to-noise ratio, not a probability.

How to read it. Look at how far t sits from 0: further out (in either direction) means a stronger difference relative to noise, and the sign just shows which group or direction is higher.

Common misread. t by itself is not a p value and not an effect size; a large t can come from a tiny difference measured very precisely.

the U statistic (U) · Compare

A Mann-Whitney statistic equivalent to counting pairwise orderings between groups, with tied pairs contributing half. Pandion Plots displays the smaller of the two complementary U values, while rank-biserial sign follows jamovi's first-sample convention.

How to read it. Interpret U through the group sizes and its null distribution; report the group distributions and rank-biserial effect.

Common misread. U is not itself a difference in means or medians, and software may display U for a particular group rather than the smaller U.

the V statistic (V) · RM

Pandion Plots removes zero paired differences, ranks the absolute nonzero differences, and reports V as the sum of ranks attached to positive differences, matching R's convention.

How to read it. Interpret V through its null distribution and p value; report the paired-difference distribution and rank-biserial effect size.

Common misread. V is not a median and different software can report a different signed-rank sum, so always name the convention when comparing output.

the z statistic (z) · Compare, RM

A standardized score saying how many standard errors a result sits from what the null expects. The rank tests here always report one next to U or V; in small samples the p value may come from an exact calculation rather than from z.

How to read it. Bigger means a more surprising result under the null. Next to U or V it is shown as a plain distance with no sign, so read direction from the group summaries or the sign of the effect size.

Common misread. z is a distance in standard-error units, not a probability; the p value is the probability piece, and a big z still does not mean the effect is large.

ANOVA and omnibus

Omnibus test · Compare, RM

An omnibus test asks one broad question about several values at once,for example, whether all group means are equal. A significant result says the joint null does not fit the data well under the model, but not which group or contrast differs.

How to read it. Use planned contrasts or follow-up comparisons that account for multiple testing to locate and estimate the differences.

Common misread. A non-significant omnibus test does not prove all groups equivalent, and a significant one does not license every pairwise claim.

One-way ANOVA · Compare

One-way ANOVA compares the population means of groups defined by one categorical variable. It asks whether differences among group means are large relative to variation within groups, using one pooled error variance. With two groups, Pandion Plots' F equals Student's t squared.

How to read it. Read F with its degrees of freedom and p value, then use effect estimates and planned or multiplicity-aware comparisons to describe where differences lie.

Common misread. The standard test assumes independent observational units, a common error variance, and normal errors for exact small-sample inference. It does not show which means differ or whether differences are important.

Two-way ANOVA · Compare

Two-way ANOVA models an outcome using two categorical factors. It tests an overall main effect for each factor and an interaction,whether one factor's pattern changes across levels of the other.

How to read it. Look at the interaction before summarizing the main effects, because an effect that changes across the other factor's levels can make an overall average incomplete or misleading.

Common misread. Interaction depends on scale: a pattern can be additive on one transformed outcome scale and interactive on another.

Type III sums of squares · Compare

Type III sums of squares test each ANOVA term after accounting for all the other terms, including interactions. Pandion Plots uses sum-to-zero coding and matches jamovi's convention when every combination of factor levels has data.

How to read it. The resulting sum of squares is used in that term's F statistic. Its meaning depends on the contrast coding and the interactions included in the model.

Common misread. Type III term sums of squares are adjusted quantities, not mutually exclusive pieces that must add to total SS. Empty cells make some hypotheses non-estimable; Pandion Plots refuses that factorial omnibus.

Main effect · Compare

A main effect compares one factor's model-based averages after averaging over the levels of the other factor. It asks whether those marginal means differ; it does not mean the factor acts 'by itself.'

How to read it. A small p is evidence that those modeled averages are not all equal.

Common misread. A main effect is not a factor acting 'by itself.' Under interaction, averaging can conceal reversals or changing effects, so inspect cell means and simple effects.

Interaction · Compare

An interaction means the effect of one factor depends on the level of the other factor. In plain terms, the pattern for one variable changes depending on the other variable.

How to read it. A small p for the interaction is evidence that one factor's effect changes across the levels of the other, so read each factor's effect within the levels of the other rather than on its own.

Common misread. A non-significant interaction is not proof the effect is truly constant across conditions; it just means you did not detect a difference in the pattern.

F statistic (F) · Compare, RM

F compares the variation represented by an ANOVA term with the error variation used for that term. Larger F values mean the term is large relative to the model's noise.

How to read it. Interpret F with both degrees of freedom and its p value. A large F with a small p is evidence against the relevant null under the model, not proof of a real or important difference.

Common misread. F is not an effect size and different ANOVA terms can use different denominators, especially in repeated-measures designs.

One-way repeated-measures ANOVA · RM

A test of condition means when the same subjects are measured in every displayed condition. Pandion Plots uses subjects with complete data for all conditions and applies the Greenhouse-Geisser correction; with two conditions, F equals paired t squared.

How to read it. A small p is evidence that the condition means are not all equal. Use paired follow-up comparisons with a multiple-testing adjustment to find and estimate the differences.

Common misread. Subjects must be independent of one another and observations correctly paired. Greenhouse-Geisser addresses sphericity, not outliers, missing-data bias, carryover, or dependence between subjects.

Greenhouse-Geisser correction (eps) · RM

A correction for repeated-measures ANOVA when the sphericity assumption may not hold. Pandion Plots estimates a number called epsilon and uses it to reduce both degrees of freedom before calculating the p value.

How to read it. For k repeated conditions, epsilon lies between 1/(k - 1) and 1. Values below 1 produce a more conservative test; epsilon = 1 leaves the degrees of freedom unchanged.

Common misread. Epsilon is an estimated correction factor, not a test result or an effect size. Automatic correction does not repair other design or model problems.

Sphericity · RM

An assumption of repeated-measures ANOVA: the differences between every pair of conditions should have roughly equal variances. When it does not hold, the ordinary test can flag differences too readily, which is why the Greenhouse-Geisser correction exists.

How to read it. You do not read a number here; a lower epsilon on the ANOVA line means a stronger correction is being applied.

Cousineau-Morey within-subject error correction · RM

An error-bar method for repeated-measures data. Pandion Plots first removes each subject's overall level across the displayed conditions, then applies Morey's correction before computing SD, SE, or a confidence interval. The plotted mean itself does not change.

How to read it. The bars reduce stable person-to-person differences and summarize normalized condition-level spread or uncertainty. They can be wider or narrower than ordinary bars.

Common misread. These are not error bars for a particular pairwise difference, not a measure of how reliably each person changed, and not suitable for comparing independent groups. Bar overlap is not a general significance test.

Multiple-comparison corrections

None (no correction) · Compare, RM, Freq

With no correction, each test keeps its own p value and alpha without accounting for the rest of the family. If several null hypotheses are true, the chance of at least one false positive is usually greater than the per-test alpha.

How to read it. Use unadjusted results only when the tests genuinely stand alone under the analysis plan, or when controlling a family-level error rate is not the goal.

Common misread. Calling results exploratory does not make the accumulated false-positive risk disappear; disclose the number and selection of tests.

Bonferroni · Compare, RM, Freq, Corr

Bonferroni limits the chance of one or more false positives across a chosen family to no more than alpha. It does this by multiplying each p value by the number of tests, up to 1, which is equivalent to dividing alpha by that number. The guarantee does not require independent tests.

How to read it. Compare the adjusted p values with the original alpha and report what counted as the family.

Common misread. It controls an error probability; it does not guarantee zero false positives. Its conservatism can reduce power, especially with many dependent tests.

Holm · Compare, RM, Freq, Corr

Holm first orders the p values, then applies a step-down version of Bonferroni. It controls the same family-wise error rate even when tests are dependent and is never less powerful than ordinary Bonferroni.

How to read it. Compare Holm-adjusted p values directly with alpha and report the family.

Common misread. Greater power than Bonferroni does not guarantee that every additional rejection is true; the procedure controls a long-run family error rate.

Benjamini-Hochberg (FDR) · Compare, RM, Freq, Corr

Benjamini-Hochberg controls the expected proportion of false positives among the hypotheses it rejects, rather than the chance of any false positive. This guarantee holds for independent tests and for common forms of positive dependence.

How to read it. Compare BH-adjusted p values with the chosen FDR level, and state which tests formed the family. BH often finds more results than family-wise methods because it controls a different error rate.

Common misread. It does not promise that this particular finding is true or that the realized false share in this one analysis is below the target. Arbitrary dependence requires additional justification or another procedure.

Tukey (studentized range) · Compare

Tukey's method compares every pair of independent-group means while controlling the family-wise false-positive rate for the whole set. It uses the pooled one-way-ANOVA error variance and assumes normal errors with equal population variances.

How to read it. Compare its family-adjusted p values directly with alpha. Pandion Plots calculates them from the pooled ANOVA error term rather than by multiplying separate Welch p values.

Common misread. Unequal variances or a family that is not all pairwise means calls for a different procedure; Tukey does not apply to rank or paired tests in Pandion Plots.

Games-Howell · Compare

Games-Howell compares every pair of independent-group means while allowing the groups to have different variances and sample sizes. It uses separate variance estimates and adjusts the p values for the full set of pairwise comparisons.

How to read it. Compare each adjusted p value directly with alpha. The adjustment accounts for both unequal variances and multiple comparisons.

Common misread. It still assumes independent units and a suitable mean-based sampling model. In Pandion Plots it does not apply to paired or rank-based tests.

Dunnett (vs control) · Compare

A correction for the specific case where you compare several treatment groups only against one control group, not against each other. Because it tests fewer comparisons, it keeps more sensitivity than comparing every pair.

How to read it. Each adjusted p value tells you whether that treatment group differs from the control; compare it to your usual cutoff.

Common misread. It assumes independent units and a defensible common-variance normal linear model. It says nothing about treatment-versus-treatment contrasts and is not an unequal-variance alternative.

Descriptives and shape

Cell · Compare, RM, Dist, Freq, Likert

A cell is one group in the chart: a single bar, box, or point identity, defined by its category (and its panel if the chart is split into panels). All the numbers in a summary row describe that one cell.

How to read it. Read the row's label to see which group the cell is (for example, the category name, or the panel and category together when the chart is faceted).

Mean (M) · Compare, RM, Dist, Likert

The mean is the arithmetic average: add up all the values in the cell and divide by how many there are. It is the balance point of the data.

How to read it. A higher mean sits further along the value axis; compare means across cells to see which group scored higher on average.

Common misread. The mean is not the most common value and not the middle value; a few extreme scores can pull it away from where most of the data sits.

Median (Mdn) · Compare, RM, Dist

The median is the middle of the sorted data. At least half the observations are at or below it, and at least half are at or above it. When there is an even number of observations, Pandion Plots averages the two middle values.

How to read it. Read it as a center that is less affected than the mean by a few very high or very low values.

Common misread. With tied values, it is not always true that exactly half are strictly below and half strictly above. A gap between the mean and median can suggest an uneven shape, but it does not prove the distribution is skewed.

Mode (Mo) · Compare, RM, Dist

The mode is the value that occurs most often in the sample. When several values share the highest count, Pandion Plots reports the smallest of them and marks the cell with an asterisk; when every value occurs exactly once there is no mode and the cell shows a dash.

How to read it. Read it as the most typical single value. It is most informative for counts, ratings and other data with a small set of repeated values, and least informative for measurements where nearly every value is distinct.

Common misread. The mode is not a center in the sense the mean and median are: it can sit at one end of the data, and a distribution can have several. A reported mode of a continuous measurement usually reflects rounding, not a real peak.

SD (standard deviation) (SD) · Compare, RM, Dist

The sample standard deviation, or SD, measures how spread out the observations are around their mean, in the same units as the data. Pandion Plots uses the common sample formula based on n - 1.

How to read it. A larger SD means the observations are more spread out. A few extreme values can make SD much larger.

Common misread. SD describes variation in the observed values, not how precisely the mean has been estimated. In Repeated Measures, a within-subject SD is based on Cousineau-Morey normalized values, so it does not represent the raw differences between people.

SE (standard error of the mean) (SE) · Compare, RM

The standard error estimates how much the sample mean would bounce around if you repeated the study many times. For an ordinary independent cell it is the SD divided by the square root of n. Repeated Measures can instead use a selected within-subject or between-subject method; the table footnote identifies it.

How to read it. Read it as the wobble in the mean itself; a smaller SE (often shown as a shorter error bar) means the mean is estimated more precisely. In Repeated Measures, use the method named below the table.

Common misread. SE is about the precision of the mean, not the spread of the people. In Repeated Measures it is not necessarily the ordinary SD divided by the square root of n.

Min and Max · Compare, RM, Dist

The minimum is the smallest value in the cell and the maximum is the largest. Together they mark the full range the data cover.

How to read it. Read them as the endpoints of the data; the gap between them shows the total range, and a lone extreme value can stretch that gap.

Class interval (bin) · Dist

One slice of the number line used to group continuous values for a histogram or frequency table: every case whose value falls inside the interval is counted in that bin.

How to read it. Read an interval row as: this many cases fall between the two endpoints. Changing the number of bins redraws the intervals, so the counts shift with them.

Common misread. Bin edges are a display choice, not a property of the data; two honest histograms of the same data can look different because their bins differ.

Skewness · Dist

Skewness summarizes asymmetry in a distribution. Positive skewness usually reflects a longer or more influential right tail, and negative skewness a longer or more influential left tail. A symmetric distribution has skewness 0, but a value near 0 does not by itself prove symmetry.

How to read it. Use the sign as a guide to direction and the magnitude as a rough guide to strength. Values above about 1 or below about -1 are sometimes treated as notably skewed, but this is a convention, not a cutoff.

Common misread. Skewness does not by itself say that the data are wrong or unusable. Mild asymmetry is common, and very different shapes can have similar skewness values.

Kurtosis (excess kurtosis) · Dist

Pandion Plots reports sample-adjusted excess kurtosis, a measure that gives extra weight to observations far from the mean. A normal distribution has excess kurtosis 0. Positive values indicate greater tail extremity than normal; negative values indicate less.

How to read it. Compare it with 0, but inspect the graph too: even one extreme observation can change kurtosis substantially.

Common misread. Kurtosis is not simply the height or pointiness of the center. A positive value does not guarantee that this particular sample contains more outliers.

Shapiro-Wilk W (W) · Dist

The Shapiro-Wilk test checks whether the pattern of ordered observations is consistent with a normal distribution. W is usually closer to 1 when the sample is more consistent with normality, but its meaning also depends on sample size. Pandion Plots uses R's shapiro.test for 3 to 5,000 non-missing values.

How to read it. A small p is evidence against the normal model under the test. A larger p means the test did not detect a departure.

Common misread. W is not a percentage or a stand-alone closeness score. Small samples have low power and large samples can detect inconsequential departures, so inspect the Q-Q plot and the analysis's sensitivity to non-normality.

Whisker (box plot) · Compare, RM, Dist

In a box plot, each whisker reaches from the box to the most extreme observed value that is still inside the 1.5 x IQR fence. Values beyond a fence are drawn separately. Pandion Plots' violin inner whiskers are an exception: they extend to the observed minimum and maximum.

How to read it. Read a box-plot whisker as the reach of the observations not flagged by the fence rule. Its length depends on both the data and the rule, so it is not a direct measure of spread.

Common misread. A box plot's whisker does not always reach the minimum or maximum, it stops at the last value inside the 1.5 x IQR fence. Only the violin's inner whiskers run to the extremes.

Outlier (1.5 x IQR rule) · Compare, RM, Dist

On a box plot, Pandion Plots flags an observation below Q1 - 1.5 x IQR or above Q3 + 1.5 x IQR and draws it as a separate point. The separate Outliers overlay can use a different multiplier or a standard-deviation rule.

How to read it. Treat a flagged point as a reason to inspect the value and its context. It is outside a chosen rule's boundary, not automatically an error.

Common misread. Being flagged does not make a point an error or something to delete, it is a distance rule, not a verdict on the data.

IQR (interquartile range) · Compare, RM, Dist

The interquartile range is the spread of the middle 50% of the data: the third quartile (Q3) minus the first quartile (Q1). It is exactly the extent of the box in a box plot (its height on a vertical chart, its length on a horizontal one).

How to read it. Read the IQR as a robust measure of spread that ignores the extremes, a taller box means more variable middle-of-the-pack values.

Common misread. The IQR describes the middle half only, it says nothing about how far the tails or outliers reach.

Quartile / fence (Q1, Q3) · Compare, RM, Dist

Q1 and Q3 mark the 25th and 75th percentiles, using R's type-7 calculation. The interquartile range, or IQR, is Q3 - Q1. The default box-plot fences are Q1 - 1.5 x IQR and Q3 + 1.5 x IQR.

How to read it. The box spans Q1 to Q3; whiskers end at the most extreme observed values inside the fences, and observations beyond them are flagged.

Common misread. Quantile conventions can differ across software, especially in small samples. A flagged point is not automatically an error or a member of a different population.

Frequencies and chi-square

Chi-square test of independence (chi2) · Freq

The chi-square test of independence asks whether two categorical variables are associated. It compares the observed cell counts with the counts expected if the variables were independent. Pandion Plots reports Pearson's uncorrected chi-square test and its large-sample p value, including for 2 x 2 tables.

How to read it. A small p value means the observed pattern would be unusual if the variables were independent. Report chi-square, degrees of freedom, p, N, expected-count checks, and Cramer's V.

Common misread. The approximation assumes independent observational units and adequate expected counts, and the categories within each variable should be mutually exclusive. A significant result does not show that the association is strong or causal.

the chi-square statistic (chi2) · Freq

A single number that adds up how far every observed count sits from its expected count, scaled by the expected count. Bigger values mean the observed counts stray further from what the null predicts.

How to read it. On its own the number is hard to judge; read it against its degrees of freedom through the p value, since the same chi-square means different things at different table sizes.

Common misread. Chi-square generally grows with both discrepancy and sample size, so it is not an effect-size measure. Pair it with Cramer's V or Cohen's w.

expected count · Freq

An expected count is how many observations a cell would contain on average if the null hypothesis were true. For independence, Pandion Plots calculates it as row total times column total divided by N. For its goodness-of-fit test, it divides N equally across the categories.

How to read it. Compare observed and expected counts. Also check the smallest expected count, because very small expected counts can make the chi-square p value inaccurate.

Common misread. The familiar cutoff of 5 is only a rule of thumb. Accuracy depends on how many cells have small expected counts and how small they are. Pandion Plots does not automatically switch to an exact or simulated test.

standardized residual · Freq

For each cell, Pandion Plots' adjusted standardized, or Haberman, residual shows how far the observed count is above or below the expected count after scaling for that cell's sampling variation. With sufficiently large expected counts, it behaves roughly like a standard normal z score under independence.

How to read it. Positive means more cases than expected and negative means fewer. Absolute values around 2 or larger can help locate cells that contribute strongly to the overall departure.

Common misread. A table contains many residuals. Treating every value beyond +/-1.96 as a separate unadjusted test increases false positives, so use residuals as diagnostic clues alongside the overall test and multiplicity-aware follow-up.

goodness-of-fit test (chi2) · Freq

The goodness-of-fit test asks whether one categorical variable follows an expected distribution. In Pandion Plots, that expected distribution is an equal split across the k observed categories. Pearson's chi-square test then uses k - 1 degrees of freedom and a large-sample p value.

How to read it. A small p value is evidence against an equal population split. Report chi-square, degrees of freedom, p, N, expected counts, and Cohen's w.

Common misread. The overall test does not identify which categories differ. Small expected counts can make the approximation inaccurate, and an equal split may be the wrong scientific null if another distribution was expected.

Cramer's V (V) · Freq

An effect size for the chi-square test of independence that rescales chi-square to run from 0 (no association) to 1 (perfect association), so it does not balloon with sample size. It answers how strongly the two variables are related, separately from whether the relationship is significant.

How to read it. Read it as a strength on a 0 to 1 scale, where larger means a tighter link; the size of a meaningful V depends on the table shape, so treat any benchmark as a rough guide, not a rule.

Common misread. V measures strength of association, not certainty or significance; a small V can still be significant in a large sample, and a large V can be non-significant in a small one.

Cohen's w (w) · Freq

An effect size for the goodness-of-fit test, measuring how far the observed proportions stray from the expected ones on a scale that does not depend on sample size. It captures the size of the mismatch, separate from its significance.

How to read it. Larger w means the counts depart further from the expected proportions; Cohen's rough benchmarks are about 0.1 (small), 0.3 (medium), and 0.5 (large), which are conventions, not laws.

Common misread. w reports the magnitude of the departure, not whether it is significant or certain; read it alongside the p value, not instead of it.

two-proportion z-test (z) · Freq

This test asks whether two population proportions are equal. For independent groups, Pandion Plots uses the pooled standard error required by the null hypothesis. When the two proportions are category shares from the same sample, it uses a variance that accounts for their dependence and identifies that version in the results.

How to read it. The signed z value is the observed difference in proportions divided by its null standard error. The p value describes how unusual a difference at least this large would be if the population proportions were equal and the large-sample approximation were adequate.

Common misread. Small counts can make the normal approximation poor. Statistical significance does not give the gap's magnitude, so report the signed difference and an appropriate confidence interval when available.

difference in proportions (delta p) · Freq

The plain gap between two proportions, one minus the other, reported on the same scale as the proportions themselves. It is the effect size that goes with the two-proportion z-test.

How to read it. Read it directly as the size of the gap: a difference of 0.15 means one group's proportion is 15 percentage points higher than the other's, and the sign shows the direction.

Common misread. This difference is the size of the gap, not its reliability; a large gap from tiny samples can be non-significant, and a small one from large samples can be significant.

% of Total · Freq, Dist

A displayed percent is a count divided by the total used by the current chart, then multiplied by 100. In Frequencies, the usual denominator is the visible total within each panel. For 100% filled bars, it is the visible total within each category. In Distribution histograms, each group's proportion bars are normalized separately.

How to read it. Name the denominator when reading the value: percent of the panel, percent within a category, or percent within a distribution group. Only the matching complete set sums to about 100%, apart from rounding.

Common misread. Hidden frequency bars are excluded from the displayed denominator, even though the Statistics panel's raw-count table retains full-data counts. A displayed percent can therefore change when a bar is hidden.

Cumulative % · Freq, Dist

Cumulative % is a running total in a defined order. Distribution bins always accumulate from the lowest interval upward; sorting that table by count or percent changes only the displayed row order, not the calculation. Frequency categories accumulate in chart order within each panel.

How to read it. Read it as the percentage accumulated through this category or interval in the underlying order and within the stated denominator.

Common misread. A visually last row need not show 100 after a table is re-sorted, because sorting display rows does not change the underlying accumulation order.

Proportion (statistic) · Freq, Dist

As a Statistic choice, Proportion shows the 0-to-1 fraction form of a percent (0.42 instead of 42%). It is the same information as a percent, just on a different scale, and an alternative to raw Count.

How to read it. Read a proportion of .42 as 42% of the total, multiply by 100 to get the familiar percent.

Common misread. Proportion and percent carry identical information, do not read the smaller-looking numbers as smaller quantities.

Correlation and reliability

Pearson r (r) · Scatter, Corr

Pearson r measures how strongly two numeric variables move together in a straight-line way, from -1 (perfect downward line) through 0 (no linear pattern) to +1 (perfect upward line). It captures linear relationships only, so a strong curved pattern can still show a small r.

How to read it. Read the sign for direction (positive means they rise together, negative means one rises as the other falls) and the distance from 0 for strength: near 0 is weak, and near -1 or +1 is strong.

Common misread. r is sensitive to outliers and range restriction, can miss nonlinear dependence, and does not establish causation. Its p value and Fisher interval require independent observational units and their sampling assumptions.

Spearman rho (rho) · Scatter, Corr

Spearman rho is Pearson correlation applied to the variables' ranks. It measures monotonic association from -1 to +1: whether larger values of one variable tend to accompany consistently larger or consistently smaller values of the other.

How to read it. Read sign as direction and magnitude as monotonic strength; unlike Pearson r, exact spacing between values does not matter after ranking.

Common misread. Ranks reduce sensitivity to extreme magnitudes but do not make rho immune to influential observations, ties, restricted ranges, or non-monotonic relationships.

Fisher-z confidence interval · Scatter

This interval gives a range of population correlations calculated from the sample. For Pearson r with at least four complete pairs, Pandion Plots transforms r to Fisher z, builds the interval there, and converts the endpoints back to the -1 to +1 correlation scale.

How to read it. If this method were repeated across many similar samples under its assumptions, intervals at the stated level would contain the fixed population correlation that often. A narrower interval means a more precise estimate. A matching two-sided interval that excludes 0 agrees with rejecting a zero correlation at the corresponding alpha level.

Common misread. It does not mean there is a stated probability that the fixed population correlation lies inside this one interval. Coverage can be inaccurate with very small samples or when the assumptions behind Pearson correlation fit poorly.

Slope (b) · Scatter

The regression slope is how much the y variable is predicted to change for each one-unit increase in the x variable, drawn as the tilt of the best-fit line. Its size depends on the units of your variables, so a slope of 2 means something different for dollars than for millimeters.

How to read it. Read it as: for every 1 unit more of x, the predicted y rises (or falls, if negative) by this many units; the sign matches the direction of the correlation.

Common misread. A large slope is not the same as a strong relationship, since slope depends on measurement units while strength is carried by r and R-squared.

Strongest pair · Corr

The pair with the largest absolute value of the currently selected matrix coefficient: Pearson r, Spearman rho, or Kendall tau-b. It is chosen only from pairs with computable coefficients in the displayed variable set.

How to read it. Check the selected method and sign. 'Strongest' is a relative ranking within this matrix, not a claim of significance, practical importance, stability, or causation.

Common misread. Because the app searches across several pairs and highlights the largest sample coefficient, that winner will often look stronger than it would in new data. Treat it as a lead to investigate, not a confirmed result.

Cronbach's alpha (alpha) · Likert

Cronbach's alpha summarizes how a set of scored items hangs together in this sample. It is calculated from the item variances, their covariances, and the number of items. Pandion Plots uses respondents with complete data on all items after any reverse scoring.

How to read it. Report alpha with the number of items, sample size, scoring decisions, and missing-data handling. Interpreting alpha as reliability also assumes, among other things, that items contribute equally to the common score and that their errors are uncorrelated.

Common misread. There is no universal .70 pass mark, and alpha can be negative. Alpha does not by itself show that a scale is one-dimensional, valid, stable over time, or equally reliable for every subgroup or score level.

Reverse-scored item ((R)) · Likert

Reverse scoring flips an item's numeric direction so that high and low scores line up with the intended scale direction. For a shared discrete scale with k response levels, Pandion Plots changes x to k + 1 - x before calculating percentages, means, and alpha. It does not apply this operation to variables handled as continuous because they have many distinct levels.

How to read it. The (R) marker means that the discrete item has been reflected. Reverse an item only when its intended meaning and coding require it.

Common misread. A negatively worded item is not automatically reverse-keyed. Reversal also cannot repair ambiguous wording, multiple dimensions, or a poorly specified scale.

Internal consistency · Likert

Internal consistency describes how responses to items intended for one combined score relate to one another in a sample. Cronbach's alpha is one common summary. Consistency does not mean that people answer every item identically, and it becomes a reliability claim only under a suitable measurement model.

How to read it. Before interpreting one coefficient, check the item content, scoring direction, dimensionality, and pattern of relationships among the items.

Common misread. Strong item relationships can come from redundancy, shared wording, method effects, or several correlated dimensions. They do not by themselves prove one dimension or construct validity.

Kendall tau (tau-b) (tau) · Scatter, Corr

Kendall's tau is a rank-based correlation from -1 to +1 that measures how often two variables' orderings agree. It compares every pair of cases: pairs ordered the same way on both variables (concordant) count for it, pairs ordered opposite ways (discordant) count against it. Pandion Plots computes the tau-b variant, which adjusts for tied values, and it is an alternative to Pearson and Spearman.

How to read it. Read tau near +1 as 'when one goes up the other almost always does too,' near 0 as no consistent ordering, near -1 as reliably opposite.

Common misread. Tau is usually smaller than Spearman's rho on the same data, that is a scale difference, not a weaker relationship.

Diverging color scale · Corr

A diverging color scale uses two hues that meet at a neutral midpoint, here white at r = 0. It encodes both the sign and the strength of a correlation, unlike a one-hue sequential ramp that only shows magnitude.

How to read it. Read the hue for direction (one color for positive, the other for negative) and the depth of color for strength.

Common misread. A pale cell means a correlation near zero, not missing data, and the two ends are opposite signs, not just 'more' and 'less.'

Lower / upper triangle (correlation matrix) · Corr

A correlation matrix is symmetric: the cell for A-with-B equals the cell for B-with-A. So the lower and upper triangles mirror each other, and showing only one removes the redundancy.

How to read it. Read a single triangle as the full set of unique pairs, nothing is lost by hiding the mirror half.

Common misread. The two triangles are not different results, they are the same correlations shown twice.

Diagonal (correlation matrix) · Corr

Pandion Plots displays 1 in every diagonal cell as the conventional self-correlation reference. Mathematically, a correlation is undefined for a variable with no variation, even though the display still uses 1 on its diagonal. Because the diagonal does not compare two different variables, it can be shown or hidden.

How to read it. Read a diagonal 1 as a display convention, not as a finding or as evidence that the variable can form valid correlations with other variables.

Common misread. The perfect 1s on the diagonal are a definition, not a finding about your data.

Significance stars (correlation matrix) · Corr

Stars use the fixed ladder * p < .05, ** p < .01, and *** p < .001, but Pandion Plots suppresses a star whenever that p also fails the chart's Alpha setting. When Adjust p is on, both stars and cell treatment use the adjusted p.

How to read it. More stars means a smaller p within the fixed ladder. Read the exact p and Alpha setting for the full decision.

Common misread. When Alpha is above .05, a p between .05 and Alpha can pass Alpha yet receive no star. Therefore no star does not always mean 'not significant at the selected Alpha.' Stars never indicate effect size or importance.

Non-significant cells treatment · Corr

This setting controls how the matrix displays cells whose p value is not below Alpha, after any p adjustment. You can show them normally, fade them, blank them, or cross them out. The setting changes only the display.

How to read it. Read a faded, blank, or crossed cell as 'did not meet the selected significance threshold,' not as a zero or missing correlation.

Common misread. A non-significant result does not prove that the population association is zero. It can reflect a small effect, an imprecise estimate, or both.

Smoothing and density curves

Silverman's rule of thumb (bandwidth) · Compare, RM, Dist

Bandwidth controls how much a density curve is smoothed. Pandion Plots first chooses an automatic width using Silverman's rule of thumb: h = 0.9 times min(SD, IQR/1.34) times n^(-1/5). If IQR is 0 it uses SD, and if there is no usable spread it uses width 1. The Bandwidth control multiplies this automatic value.

How to read it. Below 1 reduces smoothing and above 1 increases it. Inspect whether important features persist across reasonable nearby settings.

Common misread. The slider value is not the bandwidth in data units, and this rule is not optimal for every distribution, especially multimodal, bounded, or very small samples.

Kernel (kernel density estimate) · Dist

A kernel density estimate places a small smooth bump at every observation and adds the bumps together. The Kernel setting chooses the bump's shape, while Bandwidth controls its width. Bandwidth usually changes the visible curve more.

How to read it. Try reasonable nearby bandwidths and, when useful, different kernels. Features that remain visible across those choices are more stable than bumps that appear under only one setting.

Common misread. The curve is an estimate, not a uniquely determined outline of the population. Near a hard boundary such as zero, it can spill into impossible values, and small samples can produce unstable bumps.

Density (as a statistic / y-axis) · Dist

As a Statistic choice, Density rescales a histogram so the total area under the bars equals 1 (a probability density) instead of showing raw counts; with a Group By variable, each group's own bars are scaled to area 1 separately. It lets you compare distributions of different sample sizes on the same footing.

How to read it. Read the y-axis as density, not as a count or percent. A bin's fraction is its height times its width, and all bar areas, not all bar heights, add to 1.

Common misread. A density value like 0.04 is not a count or a percent, it only means something once you multiply by the bin width.

Gaussian kernel · Dist

The Gaussian kernel is an unbounded normal-shaped weighting function centered at each observation. Every observation contributes some weight at every x, although distant contributions quickly become tiny.

How to read it. It produces a smooth estimate and is a common default. With comparable effective bandwidths, kernel shape usually matters less than bandwidth.

Common misread. Gaussian refers to the smoothing kernel, not an assumption that the data or population are normally distributed.

Epanechnikov kernel · Dist

The Epanechnikov kernel uses a rounded, parabolic bump. An observation affects the curve only within a limited distance set by the bandwidth; beyond that distance, its weight is zero.

How to read it. It often produces a curve similar to other kernels. Bandwidth usually changes the result more than the choice between Epanechnikov and Gaussian bumps.

Common misread. This kernel has a theoretical efficiency advantage under particular large-sample conditions, but that does not guarantee the best estimate for a particular dataset, especially near boundaries.

Rectangular kernel · Dist

The rectangular (uniform) kernel is a boxcar bump: every point within a cutoff distance set by the bandwidth counts equally, and points beyond it count not at all. It produces a blockier, step-like density.

How to read it. Read the rougher look as a feature of the flat bump shape, not as extra detail in the data.

Normal curve overlay · Dist

The normal overlay is a bell-shaped curve fitted separately to each displayed group using that group's sample mean and SD. Pandion Plots rescales it to match Count, Density, or Proportion bars. It is a visual reference, not proof that the data are normal.

How to read it. Compare systematic shape differences such as skew, tail mismatch, or multiple modes, while remembering that binning and sample variability affect the appearance.

Common misread. Neither visual agreement, Shapiro-Wilk, nor a Q-Q plot can confirm that a population is exactly normal. Use them together to assess whether departures matter for the intended analysis.

Scatter fits and overlays

LOESS (locally weighted smoothing) · Scatter

LOESS is a fit that follows the data's local trend by smoothing over nearby points, instead of forcing one straight or polynomial line through everything. It is useful when the relationship bends in ways a single equation would miss.

How to read it. Read the LOESS curve as a flexible summary of where y tends to sit as x changes, its wiggle is controlled by the Span.

Common misread. It is a description of this sample's shape, not a tidy equation or a law you can extrapolate beyond the data.

LOESS span · Scatter

Span controls the size of the neighborhood used for each local LOESS fit. The control runs from 0.1 to 1.5, with 0.75 as the default. Smaller spans use fewer nearby observations and produce more local wiggle. Larger spans use broader neighborhoods; above 1, all observations contribute and their distance weights become more similar, producing stronger smoothing.

How to read it. Read it as a smoothness dial: turn it down to chase local detail, turn it up to see the broad trend.

Common misread. A very small span can trace noise as if it were signal, a smoother-looking curve is not automatically a better one.

OLS (ordinary least squares) · Scatter

Ordinary least squares is the standard method for drawing a straight best-fit line. It picks the line that makes the total of the squared vertical gaps between the points and the line as small as possible.

How to read it. Read the OLS line as the single straight trend that best balances all the points, its slope is the average change in y per one-unit change in x.

Common misread. Because it squares the gaps, a few far-out points can pull the line noticeably, so check for outliers before trusting the slope.

Polynomial fit (quadratic / cubic) · Scatter

A polynomial regression models the mean outcome with powers of x. A quadratic can have at most one turning point and a cubic at most two, although either may show fewer within the observed x range.

How to read it. Read the displayed curve only over the data range and use uncertainty and subject-matter reasoning to judge whether its curvature is credible.

Common misread. A cubic is not necessarily S-shaped, and adding degree can fit sample noise or behave wildly when extrapolated.

Fit line (line of best fit) · Scatter

A fit line is a modeled trend line that summarizes the overall relationship between x and y. It is a statistical estimate with assumptions behind it, not a line drawn through the actual points.

How to read it. Read it as the model's best guess at the average y for each x, and note the fit Type (linear, polynomial, LOESS) that produced it.

Common misread. It is not a connect-the-dots path, and extending it past the range of your data is a guess, not a measurement.

Data ellipse · Scatter

A data ellipse is a model-based summary of a group's center, spread, and covariance. Pandion Plots uses the sample center and covariance with a bivariate-normal model. The selected level is the share of that fitted model's probability mass inside the ellipse; it is not a confidence region for the population mean.

How to read it. The tilt shows the direction of covariance, while the shape and size summarize spread. The ellipse is not forced to contain the selected percentage of observed points, so the percentage inside this sample will vary.

Common misread. Coverage is approximate because center and covariance are estimated. Skewness, mixtures, heavy tails, or curvature can make the nominal level inaccurate.

Density contours · Scatter

Contours are rings that map where points are densest, like a topographic map of the scatter. Each line marks an equal-density level, so tightly nested rings sit over the busiest part of the cloud.

How to read it. Nested contours identify regions of higher and lower estimated density. Closer spacing means the estimated density is changing more quickly across the plot; it does not by itself mean that a contour contains more observations.

Common misread. The rings show where points pile up, not the boundary of the data; points can and do fall outside the outermost ring.

Marginal distributions · Scatter

Marginals are the one-variable distributions of X and of Y, drawn along the edges of the scatter. They show how each axis is spread out on its own, ignoring the other variable.

How to read it. Read the top marginal as the shape of X alone and the side marginal as the shape of Y alone, useful for spotting skew or gaps a scatter can hide.

Common misread. Two very different point clouds can share the same two marginals; the strips describe each variable alone, not the relationship between them.

Confidence band · Scatter, Dist

On a scatter fit, the ribbon contains a separate confidence interval for the estimated mean at each displayed x value. It is not a prediction interval for individual observations and does not guarantee that the entire curve is covered at once. The Q-Q envelope is different: it gives pointwise expected ranges for ordered sample quantiles under normality.

How to read it. For scatter fits, width describes uncertainty in the estimated mean curve at each x. For Q-Q plots, look for systematic departures rather than treating one escaped point as a stand-alone test.

Common misread. Pointwise coverage at each location does not imply the whole line or all Q-Q points are simultaneously covered at that percentage.

Bivariate Gaussian (normal) assumption · Scatter

The fitted data ellipse assumes that X and Y together form an approximately bivariate-normal distribution: roughly one oval-shaped population described by its center, variances, and covariance.

How to read it. Treat the ellipse as a model-based summary when the cloud is roughly one oval-shaped population.

Common misread. Skewness, mixtures, heavy tails, outliers, or nonlinear structure can invalidate its nominal probability coverage. An oval-looking sample does not prove bivariate normality.

Heatmap bin (2-D binning) · Scatter

In a scatter heatmap the plane is divided into a grid of tiles (bins), with the same number of bins running along each axis, and each tile is colored by how many points fall in it. This is 2-D binning: each bin covers a small patch of the x-y plane, not an interval of a single variable like a histogram bar.

How to read it. Read darker or hotter tiles as more crowded regions, the Bins control sets how fine the grid is.

Common misread. These bins cover areas of the plane, not intervals of a single variable, so 'more bins' makes finer tiles, not narrower histogram bars.

Standardized residual (regression) · Scatter

Pandion Plots takes each OLS residual (observed y minus fitted y) and divides it by the sample SD of that group's residuals. The calculation always uses the straight-line fit, even when a curved fit is displayed.

How to read it. Magnitude is vertical misfit in residual-SD units and is useful for screening unusual points.

Common misread. This is a simple residual z-score, not a leverage-adjusted internally studentized residual. A large value does not by itself identify a data error or an influential observation.

Q-Q, ECDF, and specialty charts

Q-Q plot (quantile-quantile) · Dist

A Q-Q plot is a normality check: it plots your sorted data against the positions a normal distribution would predict for the same ranks. If the data are roughly normal, the points fall close to a straight line.

How to read it. Read points hugging the reference line as roughly normal, and systematic curves or S-shapes as departures such as heavy tails or skew.

Common misread. Small wiggles in the tails are normal for small samples, do not read every bend as a real violation.

Theoretical quantile · Dist

On a Q-Q plot's x-axis, the theoretical quantile is where a standard normal distribution would place each ranked observation, a z-score-like position, so the axis runs in standard-deviation units rather than your data's units. It is the 'expected under a normal distribution' benchmark that your actual data get compared against.

How to read it. Read it as the ruler along the bottom: each point's x says where a normal distribution would have placed that ranked observation.

Common misread. Theoretical quantiles are model expectations, not any value from your dataset.

Sample quantile · Dist

On a Q-Q plot's y-axis, the sample quantile is your actual observed data value, in sorted order, paired against the matching theoretical quantile. It is the real half of the comparison.

How to read it. Read each point as: a normal distribution expected this x, your data actually delivered this y.

Reference line (Q-Q) · Dist

On a Q-Q plot, the reference line shows where the points would fall if the data were normal. Pandion Plots draws it through the first and third quartiles of your data (the classic qqline convention), so it is anchored to your data's own center and spread rather than being a fixed 45-degree diagonal.

How to read it. Read distance from the line as departure from normal: points drifting off the line at the ends signal heavy or light tails.

Common misread. It is not the y = x diagonal, and its slope is not a finding: the slope simply tracks your data's spread. What matters is how closely the points follow the line, not the line's angle.

Empirical CDF (ECDF) · Dist

The empirical CDF at x is the fraction of observations less than or equal to x. It is a right-continuous step function that jumps at each distinct observed value; ties make a larger single jump.

How to read it. Read straight up from x to obtain the observed fraction at or below it.

Common misread. Pandion Plots may average the two middle values when a sample has an even number of observations. That median can fall between observed values, so do not expect the ECDF step to identify it at exactly .5.

Complement of the ECDF (1 - F) · Dist

The complement flips the ECDF to show the fraction of data ABOVE each value instead of at-or-below (1 minus F). It is sometimes called a survival curve.

How to read it. Read straight up from any x to get the share of the data that exceeded it, the curve now falls from 1 to 0.

Raincloud plot · Compare, RM, Dist

A raincloud plot combines three views: a half-violin density 'cloud' showing the shape, a box plot showing the summary, and the raw points ('rain') showing every observation. It packs distribution, summary, and data into one picture.

How to read it. Read the cloud for overall shape, the box for the median and quartiles, and the raw points for individual values and gaps.

Common misread. Raw points can overlap, so one visible dot may represent more than one observation. Do not rely on the picture alone for the exact sample size.

Pareto chart · Freq

A Pareto chart combines count bars sorted from largest to smallest with a cumulative-percentage line. It shows how quickly the leading categories accumulate the total.

How to read it. Read bars as counts and the line as their cumulative share. An 80% reference can be useful for prioritization but is not a statistical cutoff.

Common misread. The 80/20 pattern is not guaranteed and the sorted order discards any natural or temporal category order.

Showing raw data points

Jitter · Compare, RM, Dist

Jitter nudges points sideways along the category axis with small random-looking offsets so overlapping values do not stack exactly on top of each other. The offsets are seeded from the data, so they stay put across redraws instead of reshuffling. It reveals how many points are hiding at each spot.

How to read it. Read the sideways scatter as a de-cluttering trick only: the offset carries no meaning, just the value-axis position does. On a repeated-measures chart with Connect Subjects on, each person keeps the same offset at every occasion so their line stays straight.

Common misread. The sideways spread is arbitrary placement, not a second variable, so do not interpret a point's offset.

Swarm · Compare, RM, Dist

A swarm layout (a beeswarm in the wider literature) moves points sideways just enough to reduce overlap while leaving their measured values unchanged. Points stay within the selected Spread width, so some may still overlap when space is tight. Regions with many nearby values usually form wider bulges.

How to read it. Use the bulges as a rough visual cue to where values are concentrated, not as an exact density estimate. Only the value-axis position is measured; the sideways position is used for packing.

Common misread. As with jitter, the sideways position is only for packing, it is not a measured quantity.

Strip plot · Compare, RM, Dist

A strip layout adds no sideways offset. All points in a category share the same category position, so identical or nearby values may overlap and hide how many observations are there.

How to read it. One visible dot may represent several observations. Switch to jitter or swarm when seeing overlap is important.

Spread (jitter / swarm width) · Compare, RM, Dist

Spread sets how far the jitter or swarm points may fan out on each side, as a fraction of the bar or category width. It is a layout setting, not a statistic, and the Strip and No-scatter modes ignore it.

How to read it. Read it as a crowding dial: widen it when points overlap, narrow it to keep each group compact.

Common misread. This spread has nothing to do with statistical spread such as standard deviation, it only controls point placement.

Rug marks (rug plot) · Dist, Scatter

A rug draws one tick at each observation's axis position, adding raw-value locations beside a distribution or scatter display.

How to read it. Clusters of visible ticks suggest concentration and gaps suggest sparse regions.

Common misread. Identical or very close values can overlap, so visible tick count and darkness do not reliably show how many observations share a position.

Spaghetti plot / subject connectors · RM

Subject connectors draw one line per participant, joining that person's values across occasions. The tangle of lines (a spaghetti plot) lets you see individual trajectories, not just the group averages.

How to read it. Read each line as one person's path over time, look for lines that rise while others fall, which group means alone would hide.

Common misread. A rising group average does not mean everyone rose, individual lines can head the opposite way.

Axes, panels, and layout

Facet / faceting (panels) · Compare, Dist, Freq, Scatter

Faceting splits one chart into a row or grid of small panels, one per level of a variable, so you can compare patterns side by side. Each panel is the same chart drawn on just the rows belonging to that level. In Pandion Plots the variable goes in the Panels box.

How to read it. Read across the panels to compare how the pattern changes from group to group, they share the same axes by default so heights are comparable.

Common misread. Equal heights can be compared directly only while the panels share the same y-axis scale. With Free Y turned on, compare the axis numbers instead of the mark heights.

Free Y axis (independent per-panel scales) · Compare, Dist, Freq, Scatter

Free Y gives each facet panel its own y-axis range, based on the data in that panel. This can make patterns within a panel easier to see, but equal mark heights across panels no longer represent equal values.

How to read it. Read each panel using its own y-axis numbers. You can still compare numerical values across panels, but not their heights alone.

Common misread. Different scales can make a small change in one panel look as tall as a much larger change in another. Always check the numerical ranges.

Axis break (truncated axis) · Compare, RM, Dist, Freq

An axis break is the // mark that signals the value axis was cut and does not start at zero. It is a chart-integrity cue: the axis is truncated on purpose, and the mark discloses it.

How to read it. Read the // as a warning to check the axis numbers before judging how big the differences really are.

Common misread. For bars, an axis break does not remove the distortion caused by a nonzero baseline because bar length encodes value. For lines, dots, and boxes, a nonzero axis can be appropriate, but the omitted range still needs to be shown clearly.

Zero baseline · Compare, RM, Dist, Freq

The zero baseline is the principle that length-encoded charts like bars must start at zero. If a bar axis starts higher, the bar lengths exaggerate the differences between groups.

How to read it. Read bars only when they begin at zero, then a bar twice as long really means twice as much.

Common misread. Position-encoded charts (lines, dots, box plots) do not need a zero baseline the way bars do, the rule is specific to length.

Smooth / interpolation (line charts) · Compare, RM

Smooth draws a curved, interpolated path between the plotted points instead of straight line segments. It looks tidier but invents a shape for the space between your measured values.

How to read it. Read a smoothed line's peaks and dips between points as decoration, only the marked points are real data.

Common misread. The curve passes exactly through your data points, but between them it can swing higher or lower than either neighbor. Do not read those in-between bulges as measurements; only the marked points were observed.

Colorblind-safe / CVD-safe · Compare, RM, Dist, Freq, Corr, Likert, Scatter

Pandion Plots' CB-safe badge means that the app simulated two forms of red-green color-vision deficiency, protanopia and deuteranopia, and that every color pair passed its built-in minimum-separation check.

How to read it. Treat the badge as one screening result. Also inspect the CVD, tritanopia, and grayscale previews, and keep labels, shapes, or other cues that do not depend on color alone.

Common misread. No simulation can guarantee that every viewer will distinguish every color on every display or at every mark size. The badge lowers risk; it is not a universal accessibility guarantee.

Survey (Likert) charts

Diverging stacked bar · Likert

The diverging stacked bar is the default Likert chart: agree-side levels stack rightward and disagree-side levels stack leftward from a shared center line. The split at zero shows the balance of sentiment for each item.

How to read it. Every bar hangs on the same zero line, so read the balance: the farther a bar reaches right of zero, the more agreement on that item; the farther left, the more disagreement. Rank items by their right-side reach, or switch Sort items to Most agree to have the chart rank them for you.

Common misread. A neutral middle category is split around zero, so the exact center line is a display convention, not a hard count boundary.

100% stacked bar (normalized stacking) · Likert, Freq

A 100% stacked bar rescales every bar so its segments sum to 100%, showing each category's share within the bar rather than raw counts. It is built for comparing composition across bars of different totals.

How to read it. Read segment lengths as percentages of that bar. Every bar has the same total length, so compare composition rather than amount.

Common misread. Normalization hides each bar's sample size: a narrow segment from a large group can represent more cases than a wide segment from a small group.

Center / split-middle boundary · Likert

In a diverging bar, the zero line is a visual boundary from which the lower and upper response sides extend. On an odd-length scale, Pandion Plots splits the single middle category equally across that line; an even-length scale has a boundary but no middle category.

How to read it. Treat zero as an alignment reference for comparing response balance, not as an observed response value.

Common misread. Splitting a middle category is a display convention and does not classify half of those responses as favorable or unfavorable.

Net-agreement sort · Likert

Net-agreement sort orders the Likert items by net agreement, the agree-side share minus the disagree-side share. It ranks items by overall favorability rather than by any single response column.

How to read it. With Most agree, read the top item as the most net-positive and the bottom as the most net-negative; Least agree flips that order. Dragging a row afterward switches the sort to Custom.

Common misread. It sorts by the agree-minus-disagree balance, not by the count of any one level, so a strongly-mixed item can rank near neutral.

Top-box (favorable percentage) · Likert

In Pandion Plots, the favorable bar-end summary adds every response level on the agree side and excludes a neutral middle level; the unfavorable summary similarly adds the disagree side.

How to read it. Read it as the share selecting any favorable level under this chart's ordered scale and center boundary. State the included response levels when reporting it.

Common misread. Industry terminology varies: 'top-box' can mean only the single highest category, while 'top-two-box' or favorable percentage combines several. Pandion Plots' value is the full agree-side percentage, not necessarily the conventional single top box.

Exporting & sharing

The Export panel

  • Format: SVG, PDF, PNG, JPG. (SVG and PDF are vector, so they stay sharp at any size; use them for papers. PNG / JPG add a DPI choice: Screen (96) / 150 / Print (300, the default) / 600, plus Hi-res (1200) for JPG only.)
  • Filename and Save to (Downloads / Desktop / Documents) are remembered. Files are never overwritten; a duplicate name gets " (2)", " (3)"…
  • After Save, the result appears in the small Export Status item under the chart: "Saved <filename> to <folder>".
PDF notePDF export uses the R package rsvg. If it is missing, the status line says so: install it in jamovi's R with install.packages('rsvg'), or export SVG instead.

What travels with a .omv file, and what does not

  • The chart travels. Everything you set on a chart (colors, styles applied, annotations, titles, brackets) is stored in the analysis inside the .omv. A colleague who opens your file sees the chart exactly as you styled it.
  • A static copy rides along. jamovi also keeps a "Chart (static copy)" image of the figure in the results, hidden while the module draws the live chart. A colleague without the module sees that copy instead, and it is what jamovi's own HTML and PDF document exports carry.
  • There is no library to travel yet. Saved palettes and chart styles are switched off inside jamovi for now, so opening a file reads and writes nothing outside the .omv, and every look lives in the chart that carries it. Once the libraries are switched on they will live on your own machine and follow you across files, never inside a shared .omv.
  • Re-opening a shared file never silently writes exports to disk or re-saves palettes; those actions only fire when you click them.

Exporting from the app

  • One blue Export button, top right, exports whatever workspace you are in: the chart (SVG, PDF, PNG, JPG), the layout page, or the Notebook. Exporting the Notebook asks for scope first (this page, this section when there are several, or the whole Notebook) and then offers the same formats as a chart: PDF, SVG, PNG, JPG.
  • The Export chart dialog asks for the format (SVG and PDF are vector, PNG lossless, JPG compact) and a filename, then offers a Caption that appears under the exported figure, with an Add what produced this chart button that appends a statement of what produced the figure; an Image description for accessibility (embedded in SVG and PDF, and copyable for PNG and JPG); a Resolution for PNG and JPG (Screen 96 / High quality 150 / Print 300 / Hi-res 600 DPI); and a Background (As shown / Transparent / White). Notebook exports add Include each page's details and notes under the figure: the page number, the date it was kept, the analysis it came from, and your notes. Preferences sets the default format and raster DPI.
  • Vector by default. SVG and PDF stay sharp at any size, and kept Notebook pages stay vector all the way into the PDF.
  • What travels in a .pand project: everything - the data, every chart and its styling, layouts, and the Notebook. Your saved palettes and chart styles stay in your own library on your machine, so opening someone else's project can never rewrite your defaults.

Troubleshooting & FAQ

The chart area shows instructions instead of a chart

A required variable box is still empty. The empty chart offers a Choose variables button, which opens Chart setup, and a Not sure? Help me choose link, which opens the wizard with your columns ready to pick. Fill the boxes and the chart draws immediately.

A required variable box is still empty; the placeholder tells you exactly which ("Drag a categorical variable into X-Axis Variable and a numeric variable into Y-Axis Variable to render…"). Fill the named boxes and the chart draws immediately. If a variable is assigned but every value is missing, the message says so ("<variable> has no usable (non-missing) values to plot.").

A small pill says "N of M cases not shown (missing values)"

Rows with missing values on the variables the chart uses were dropped (or partially used). The pill is informational and dismissible, and it is not part of the exported figure; if the exclusion matters for readers, state it in the Figure note. Each module counts in the role-appropriate way: Repeated Measures keeps subjects at the occasions where they were measured; Correlation uses pairwise-complete cases; Likert keeps each item's own n; Scatter ignores a missing Group By value (the point still plots, ungrouped).

My bars have no error bars

Three by-design reasons: the cell has fewer than 2 observations; Error Bars is set to None; or Summary is set to Median: SE, SD, and CI formulas describe the mean, so no bar is drawn around a median (the Σ Descriptives footnote explains). Box / violin / raincloud never draw summary error bars; the shape itself carries the spread.

I hid something and want it back

Toolbar eye button → the Hidden tab lists everything currently hidden; one click restores each. The eye icon itself shows a count while anything is hidden.

Likert refuses my items, or only offers "Means"

Items must share one small response scale. If your (all-numeric) items have more than 25 distinct values they are continuous measurements, so the module switches to the means-only chart and says so. If a many-level item is text, nothing sensible can be drawn and the module explains why (many-level categorical variables belong in Frequencies).

A statistic refuses to compute

That is deliberate: Pandion Plots never computes a test that does not fit the data. The readout explains in plain language: for example, paired tests need matched within-subject data, rank and paired tests do not support every multiple-comparison correction, mixed ANOVA needs enough complete subjects in every design cell, and correlations need 3+ complete pairs. The wording points to the relevant requirement or alternative.

The chart says "Loading chart engine…"

The chart engine was not yet live in this results window for that render (jamovi ships it once and reuses it within the window). The note self-heals on the next run of the analysis (change anything, or re-run). Your options and data are unaffected.

Where do my saved palettes and styles live?

Nowhere yet. Inside jamovi, saving palettes and chart styles is switched off for now, at jamovi's request, until jamovi provides a home for settings that outlive a single file; the Save and Use as default buttons, the Chart styles tab, and Make these my default palette are not shown there. The palette you pick or build still applies to the chart and travels inside the .omv with it. The app keeps its own library and is unaffected.

Something looks stuck after an edit

jamovi recomputes in the background after each edit; heavy charts can take a beat. Panels and menus are built to survive this, but if the display ever looks wrong, any small change (or Cmd/Ctrl+Z then redo) forces a clean redraw. If the whole module misbehaves after installation or reinstallation, restart jamovi; modules load at startup.

Where do my projects, library, and autosave live?

A saved project is the .pand file you chose - it carries the data, charts, layouts, and Notebook. Between saves the app keeps a local autosave (plus a one-step backup and a recents list) in the browser's own storage on this machine, which is what the start screen restores from. Saved palettes and chart styles also live in that local storage, so they follow you across projects on this machine. A copy of them is also written into each saved .pand file, so a shared project brings its look with it; opening one adds any names you do not already have and leaves your existing entries alone.
